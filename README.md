# Инвестика CRM — дизайн-прототип

Локально запускаемый frontend-прототип CRM на React + Vite + TypeScript + Tailwind CSS.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Мастер поручений

В Windows выполните `order-wizard\serve.cmd` для работы с QORT или `order-wizard\serve.cmd --mock` для учебного справочника. [Требования PHP, подключение и запуск](order-wizard/README.md)
