# Приложение 7 к брокерскому регламенту

С 19 ноября 2026 года мастер формирует поручение на сделку, перевод между площадками или вывод на банковский счёт по отдельной карте и исходному PDF. Полный перечень реквизитов и их источников приведён в [координатной ведомости](../handoff/order-forms-2026-11/FIELD_MAPPING.md). Границы страниц, исходный файл и контрольные суммы зафиксированы в [проверке источника](../handoff/order-forms-2026-11/SOURCE_AUDIT.md).

| Прежнее значение `extra-order-type` | Действующий ID карточки и карты | Страницы исходника |
| --- | --- | --- |
| trade | `order-trade` | 122–123 |
| transfer | `order-venue-transfer` | 124 |
| withdrawal | `order-bank-withdrawal` | 125 |

Прежняя составная карточка `order-forms` и файл `poruchenie.pdf` выведены из каталога. Для прямой ссылки используйте `document-wizard.html?subject=c-011&type=<ID карточки>`. Если указан прежний ID, мастер открывает выбор документа. Одна ссылка без вида операции не определяет отдельную печатную форму.

`extra-brokerage-account` содержит код клиента, `extra-contract-number-date` — договор CRM. `selectedRequisiteId` указывает на сохранённую запись. `extra-move-amount-words`, `extra-payout-amount-words` и три выходных ключа суммы сделки сохранены. Дополнительный `orderInput` содержит только активные входные значения, `orderMetadata` — ID источника и состояние расчёта/подтверждения. Для новой заявки номер и дата хранятся в `extra-order-number` и `extra-order-date`. Разбор свободного текста прежнего `extra-order-number-date` неоднозначен. Мастер собирает номер отдельно, ставит текущую дату в часовом поясе пользователя и сохраняет выбранную им дату. Цены и суммы принимают запятую или точку. Единое поле суммы сделки получает значение из спецификации и сохраняет ручную редакцию. Валюта цены бумаги доступна для ввода по коду. В межплощадочном переводе выбор совпадающего рынка очищает противоположную сторону.

Решения по неизвестным коэффициентам QORT, внебиржевым сериям, отдельному лицевому счёту, маршрутам и ручной редакции описаны в [решениях по реализации](../handoff/order-forms-2026-11/DECISIONS.md). Результаты запуска проверок доступны в [отчёте QA](../handoff/order-forms-2026-11/TEST_REPORT.md).
