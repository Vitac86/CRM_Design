# Решения по Приложению 7

## Печатная форма и области ответственности

В мастере доступны три самостоятельных первичных поручения. Мастер ставит текущую локальную дату при открытии нового поручения. Оператор может изменить её и при необходимости заполнить номер. Такой же выбор даты доступен для срока «До определённой даты». Дата договора поступает из CRM, экспирация — из выбранной серии ПФИ. Дата раскладывается по напечатанным пробелам дня, месяца и двух последних цифр года после «20». Отмена ранее поданной заявки требует отдельного операционного процесса. Доверенность, подписи, М.П., регистрация и приём сотрудником остаются для оформления на бумаге.

Отметка «Я проинформирован, что данная сделка может привести к открытию непокрытой позиции» печатается на второй странице каждого поручения на сделку для ФЛ и ЮЛ при любом уровне риска, в том числе при незаполненном поле в карточке клиента. Сноска *** воспроизводится из утверждённого бланка.

## Данные клиента и банка

- Код счёта поступает из точного UMI-поля `num_investika` либо `subject.code`. Дефис и ведущие нули сохраняются. Договор формируется из `bo_num` и `datesign`. Номера и даты для демонстрации соответствуют брокерским договорам в локальных карточках ФЛ и ЮЛ. В рабочем подключении источник даты подписания — `datesign`.
- Ключом сохранённых реквизитов служит ID записи текущего субъекта. Фильтр учитывает валюту, владельца и явно переданные признаки архивирования, активности и применимости. Две подходящие записи требуют выбора. Единственная доступная запись предварительно выбирается и отображается в селекторе. Ноль записей блокирует выпуск.
- Прототип хранит записи внутри субъекта. Если сервис отдаёт плоский список, интеграция должна передать идентификатор владельца. Каталог и проверки в браузере обеспечивают целостность локального документа. При подключении операционного сервиса принадлежность, полномочия, маршрут и актуальность повторно проверяются по данным CRM.
- `БИК/SWIFT` берётся из выбранного маршрута. Для рублёвого или явно внутреннего маршрута принимается девятизначный БИК, для международного — SWIFT. Сведения о посреднике обязательны при признаке `requiresIntermediary`. В валютной записи с прямым маршрутом корреспондент может отсутствовать.
- `payment_account` заполняет строку счёта получателя. Для отдельной строки «Лицевой счет» используется только отдельное значение `personalAccount` того же реквизита. В реестре отсутствует подтверждённый отдельный атрибут UMI для этой строки. Дублирование номера счёта из старого демопримера устранено.
- Селектор маскирует номер счёта, печать использует всю запись. При смене реквизита десять строк пересчитываются из одного ID.

## Суммы и рынки

- Режим AUTO требует полную спецификацию с источником, шагами количества и цены, единицами, валютой и правилом округления. Величины рассчитываются как десятичные отношения на BigInt, округление выполняется один раз. Учебные параметры явно помечены `demo-spec-2026-11`. Производственные значения должен передать справочник инструментов.
- Цена и денежные суммы принимают запятую и точку. Для ввода с клавиатуры используется десятичная запятая. Валюту цены бумаги можно задать трёхбуквенным кодом. При расхождении с валютой спецификации расчёт требует ручной суммы и подтверждения. Конвертация требует собственной спецификации.
- Поддержаны цена за штуку, процент от номинала с явным типом суммы, FX с лотом и масштабом котировки и премия опциона с контрактным множителем. Для суммы с НКД требуется величина на дату расчётов. Ноябрьский бланк сам по себе не определяет clean/dirty для каждого выпуска. Для демонстрационных облигаций без подтверждённой базы, фьючерсов без денежной формулы, иных видов сделок, РЕПО и свопа автосумма недоступна. Лимитное поручение допускает сумму, которую оператор ввёл с основанием и подтвердил.
- Для рыночного поручения сумма остаётся пустой. Это прямо предписано сноской ** для ценных бумаг. В остальных ветках неизвестная рыночная цена также исключает расчёт. Страйк, премия и гарантийное обеспечение имеют разное назначение.
- Фондовый и внебиржевой рынки допускают ценные бумаги. Валютный раздел применяется на валютном рынке. Раздел ПФИ допускает внебиржевую сделку при наличии серии с зарегистрированным допуском OTC. Текущий демокаталог содержит биржевые серии. Электронный процесс поддерживает рыночное и лимитированное поручения, а условное, как и отмена, требует отдельного процесса.
- Шесть именованных площадок имеют постоянные ID. Для строки «иное» интеграция может предоставить дополнительные именованные площадки со стабильными ID через `additionalOrderVenues`. Оба селектора предлагают все площадки. Если новая площадка совпадает с ранее выбранной с другой стороны, последнее действие сохраняется, а противоположное поле очищается. Непосредственно перед печатью проверяются оба ID. Подтверждённая матрица межплощадочных ограничений в исходных данных отсутствует.
- Для денежного поручения система знает RUB, USD, EUR и CNY. Прежний код EURO распознаётся как EUR. Неподписанный дополнительный квадрат оставлен пустым до появления определённого кода валюты и правил её прописи.
- Расчётная сумма подставляется прямо в поле «Сумма сделки». После ручной правки мастер сохраняет введённое значение при изменении цены, количества и при возврате между шагами. Для текущей ветки оператор может вернуть расчёт кнопкой. Ручная редакция прописи и суммы сохраняет контрольные значения и основание в данных текущей сессии. Изменение текста, суммы, валюты или параметров сделки отзывает подтверждение. Смысл ручной прописи сверяет оператор. Элементы управления и отметка о проверке не печатаются.

## Геометрия и ограничения

Минимальный размер шрифта — 9 pt. Короткие и длинные ФИО и наименования проходят через общий preflight. Юридическое наименование в торговом поручении при необходимости занимает измеренное продолжение табличной строки. На денежных формах наименование помещается в две строки существующей ячейки. В переводе цифры с подписью занимают отдельную строку. В выводе цифры и пропись занимают соседние области. Слова переносятся общим движком абзацев, числовая дробная часть остаётся рядом с названием минорной единицы. У прописи зарезервированы три базовые строки и до трёх добавочных строк по 10,5 pt. При расширении исходные реквизиты, подчёркивания и подписи перемещаются согласованно в пределах листа. Если текст выходит за проверенные пределы, весь PDF отклоняется до скачивания. Полные изображения приложены в `screenshots/`.

Подтверждений извне, фоновой загрузки на торговую площадку, отправки в банк и публикации в этом локальном прототипе нет.
